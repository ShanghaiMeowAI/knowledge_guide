Knowledge Guide

A reusable knowledge-guide module with internal search, guide collections, public token links, visit tracking, and email sharing.

Key Features

Page ManagementMaintain categorized, searchable, access-controlled guide pages.
Guide CollectionsCombine multiple pages into a publishable guide.
Public LinksShare guides through unguessable token-protected links.
Module ExtensionsBusiness modules can add guide pages through XML data.

Where to Use It

  • Internal users read documentation from the User Guides menu.
  • Administrators maintain pages and collections under Settings > Knowledge Guides.
  • Guide collections can be published at /guide/<slug>?token=<uuid>.
  • link.tracker records visits, and the email wizard shares guides with contacts.
