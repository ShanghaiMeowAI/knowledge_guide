Knowledge Guide

通用知识库指南模块，支持后台搜索、指南合集、公开 token 链接、访问统计和邮件分享。

主要功能

页面管理维护可分类、可搜索、可权限控制的指南页面。
指南合集把多个页面组成一套可发布的手册。
公开链接通过不可猜测的 token 链接分享给外部读者。
模块扩展业务模块可以通过 XML 数据追加自己的指南页面。

使用入口

  • 内部用户通过 使用指南 菜单阅读文档。
  • 管理员在 设置 > 知识库指南 维护页面和合集。
  • 指南合集可以发布为 /guide/<slug>?token=<uuid> 公开链接。
  • 支持 link.tracker 统计访问量，并可通过邮件向导发送给联系人。
