# 业务指南与基础参考

`19` 分支面向 Odoo 19。通用模块只提供阅读、目录和发布能力，具体项目内容继续由依赖它的模块通过 XML 或 ORM 提供。

- 旧页面的 `guide_kind` 默认是 `business`，保持业务指南优先。
- `guide_kind='reference'` 的页面单独进入“基础功能参考”。默认入口不会加载这些页面的正文。
- `parent_id` 支持多级目录，不能循环引用或跨分类连接。没有父页面的旧数据继续按 `section/category` 分组。
- `related_page_ids` 在正文末尾提供关联阅读，并按读者可见范围过滤。
- 新阅读器继承原有组件，复用业务动作链接与正文处理；`get_navigation` 仅返回目录，`get_page` 按需返回正文。
- 原 `get_pages` 接口继续返回完整页面数据，兼容已有调用方。
- 项目扩展可以继承 `_guide_visible_domain()` 增加适用范围条件；控制器和关联阅读使用相同的过滤规则。
- 正文支持 `#guide:module.xmlid#anchor`。后台可在当前搜索结果以外定位页面；公开页面只在同一合集内解析指南链接，并保留 token 和语言参数。

公开合集的既有发布机制保持不变：持有有效 token 的读者可阅读合集中的启用页面。内部业务手册与可公开参考内容应分别建立合集。此次递归目录和业务/参考切换用于后台阅读器，公开合集仍保留原有分组导航。

其他项目更新子模块提交后升级 `knowledge_guide` 即可；不安装项目内容模块，就不会出现该项目的指南内容。
